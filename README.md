# AppShelf

Бесплатное приложение для удаления обычных программ Windows с просмотром остатков, резервным копированием реестра и восстановлением. **Версия 0.2.0-beta**, ранняя бета.

## Автономный загрузчик / установщик

`AppShelf-Setup.exe` содержит приложение внутри: интернет не нужен. Он проверяет SHA-256 встроенного EXE, устанавливает файлы в `%LOCALAPPDATA%\Programs\AppShelf`, по выбору создаёт ярлыки и регистрирует удаление в Windows. Саму установку пользователь запускает кнопкой «Установить». После завершения можно сразу открыть приложение.

Сборка: `./installer/build-loader.ps1`. Результат: `dist/AppShelf-Setup.exe`. Собирайте загрузчик заново после обновления основного EXE. Сценарий Inno Setup остаётся отдельным альтернативным способом упаковки.

Проверены целостность пакета, извлечение, сохранение посторонних файлов, откат файлов при имитированной ошибке и создание ярлыка. Полный цикл установки/обновления/удаления в Windows ещё требует проверки в виртуальной машине. Удаление выполняется из временной копии помощника; эта копия может оставаться в TEMP до очистки временных файлов. Резервные копии реестра и журналы AppShelf сохраняются. Интернет-загрузка пока не настроена: опубликованного релиза с постоянным URL нет.

## Запуск

Откройте `AppShelf.exe`. Portable-версия не требует установки. Windows 10/11, .NET Framework 4.8. Исходники: C# / Windows Forms, сторонних runtime-библиотек нет.

## Интерфейс

Светлый рабочий экран, тёмное боковое меню, бирюзовый акцент и встроенная иконка AppShelf. Значки программ берутся из DisplayIcon; если значок недоступен, показывается цветная монограмма. SVG, PNG и многоразмерный ICO находятся в `assets/`.

Ctrl+F — поиск, Esc — сброс поиска, F5 — обновление списка.

## Что умеет

- Показывает обычные приложения из HKCU/HKLM и обеих разрядностей реестра.
- Ищет по названию и издателю, показывает версию и папку установки.
- Запускает стандартный мастер удаления. После исчезновения программы из списка автоматически предлагает поиск остатков.
- Ищет отдельные разделы продукта непосредственно в `Software` и под разделом издателя, а также `App Paths`, `Run` и `RunOnce`, ссылающиеся на сохранённую папку установки.
- Точные совпадения реестра отмечены заранее, частичные совпадения и папки — только вручную. Двойной щелчок показывает содержимое раздела или открывает папку.
- Перед очисткой сохраняет XML-копию всех выбранных данных реестра с типами параметров и вложенными разделами. Затем проверяет, что данные не изменились со времени сканирования.
- Показывает результат по каждой записи, сохраняет журнал, восстанавливает данные реестра. Существующие записи при восстановлении не перезаписываются.
- Перемещает выбранные папки в корзину по правилам Windows. Сам AppShelf работает без администратора; для очистки HKLM запрашивает UAC.

## Обычный сценарий

1. Выберите программу → **Удалить начисто**.
2. Завершите её штатный мастер удаления.
3. AppShelf откроет поиск остатков. Просмотрите точные и частичные совпадения.
4. При желании отметьте папки. В них могут оставаться пользовательские данные.
5. Нажмите **Очистить**. Восстановление реестра доступно через боковое меню.

Если открыть поиск до удаления, будет доступен только предпросмотр. При отмене деинсталлятора AppShelf не разрешит очистку установленной программы.

## Границы очистки

Это поиск по признакам, а не доказательство принадлежности записей программе. Совпадение названия может быть ложным, а раздел под другим названием может быть пропущен. Общие разделы производителей, Windows, Classes/COM, службы, драйверы, MSI-компоненты, политики и системные ассоциации не удаляются. Microsoft Store не поддерживается. Обещания «найдёт абсолютно все следы» нет.

Копия реестра сохраняет значения и их типы, но не исходные ACL и не состояние всей Windows. Типы REG_NONE/REG_LINK и неподдерживаемые типы пропускаются до очистки. Реестр и файловая система не образуют общую атомарную транзакцию: возможны частичные результаты, они показаны в отчёте. Файлы восстанавливаются отдельно из корзины Windows. Если Windows предлагает окончательное удаление вместо корзины, внимательно прочитайте её диалог.

Защищённые папки Program Files могут потребовать отдельного запроса Windows. Если права получить не удалось, запись останется в отчёте как неочищенная. Повторное использование резервной копии не перезаписывает уже существующий раздел.

## Данные и приватность

Настройки, ожидающее удаление, задания, журналы и копии находятся в `%LOCALAPPDATA%\AppShelf`. Они могут содержать названия программ, пути и настройки, включая чувствительные значения. Хранение локальное, без шифрования. Сетевых запросов, телеметрии и автоотправки отчётов нет. Не публикуйте эту папку вместе с исходниками. Копии сохраняются после удаления самого AppShelf.

## Сборка

```powershell
./build.ps1
```

Сценарий использует системный компилятор .NET Framework. Альтернативно откройте `AppShelf.csproj` в Visual Studio с установленным .NET Framework 4.8 targeting pack.

```powershell
./AppShelf.exe --self-test
./AppShelf.exe --self-test --registry-fixture
./package.ps1
./package.ps1 -Installer
```

Для установщика нужен [Inno Setup 6](https://jrsoftware.org/isdl.php). Он устанавливает программу в профиль пользователя, создаёт меню «Пуск», необязательный ярлык и штатный деинсталлятор. Обновления используют постоянный AppId. Сценарий установщика подготовлен, но в текущей среде не скомпилирован и не проверен установкой.

Обычные тесты не меняют реальные приложения. Режим `--registry-fixture` создаёт уникальный временный раздел `HKCU\Software\AppShelfTest<GUID>`, проверяет очистку/восстановление и удаляет только этот тестовый раздел. Его копия остаётся в локальной папке AppShelf. Запускайте тесты с записью в текущую папку.

GitHub Actions собирает EXE, запускает тесты на временном разделе реестра и сохраняет portable-архив с SHA-256 как artifact. Автоматической публикации Releases нет: проверенный artifact добавляется в релиз вручную. Workflow подготовлен, удалённо ещё не запускался.

## Статус релиза

На текущем ноутбуке проверены сборка, поиск и интерфейс, резервирование, очистка и восстановление на временном HKCU-разделе. Массового тестирования чужих деинсталляторов, HKLM с UAC, установщика и разных версий Windows ещё нет. EXE не имеет цифровой подписи. Для публичной беты выполните [план релиза](RELEASE-PLAN.md).
