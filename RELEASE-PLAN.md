# План первого публичного релиза

## Позиционирование

AppShelf — бесплатный open-source деинсталлятор с понятным просмотром остатков и локальным откатом реестра. Не обещать ускорение компьютера, полное удаление всех следов или полное соответствие Revo.

## До v0.2.0-beta на GitHub

- Создать публичный репозиторий с исходниками, MIT, README, CONTRIBUTING и шаблоном bug report. Не загружать локальные копии реестра и журналы.
- Добавить своё имя/ник и скриншоты интерфейса. Проверить доступность названия перед дальнейшим продвижением.
- Запустить приложенный Windows CI. Он пока подготовлен, но ещё не выполнялся на GitHub.
- Проверить в виртуальных машинах: Windows 11, актуальная поддерживаемая конфигурация Windows 10, обычная учётная запись, UAC, 100/125/150/200% масштаба.
- Взять тестовые программы: MSI, Inno Setup, NSIS, установка на пользователя и на компьютер; отмена удаления, перезапуск деинсталлятора, требование перезагрузки, одинаковый издатель у нескольких приложений.
- Проверить выбор отдельных параметров Run/App Paths, обе разрядности HKLM, неизвестные типы данных, отказ доступа, изменившийся после сканирования раздел, восстановление и повторный запуск.
- Скомпилировать Inno Setup из `installer/setup.iss`; проверить установку, обновление поверх старой версии, удаление самого AppShelf и сохранность резервных копий.
- Вручную выпустить GitHub pre-release с portable ZIP, Setup EXE, SHA256SUMS и описанием ограничений.

## До стабильной v1.0

- Код-ревью механизма определения владельца записей; тесты общих разделов производителя и установленных соседних продуктов.
- Отдельный минимальный повышенный helper с протоколом IPC вместо файлов заданий. Текущая версия перепроверяет каждый запрос, но разделение процессов и прав стоит сделать строже.
- Устойчивый журнал операций: явные состояния «сохранено / удалено / пропущено», возобновление после сбоя и удобный список копий.
- Тесты на подмену путей/ссылки, большие разделы, низкое место на диске, закрытие приложения и отмену UAC.
- Доработка доступности: клавиатура, screen reader, высокая контрастность и корректный DPI.
- Подпись EXE и установщика доверенным сертификатом либо доступной программой подписи open-source. Подпись не гарантирует отсутствие предупреждений SmartScreen для нового файла.

## Потом

- Английский язык и стандартные ресурсы локализации.
- Приложения Microsoft Store с отдельной моделью удаления.
- Проверка обновлений через GitHub Releases по действию пользователя. Автоустановка обновлений — после проверки подписи и целостности пакетов.
- winget-манифест после стабилизации установщика и публикации версии.
- Расширение правил поиска на основе конкретных приложений с тестами; не добавлять глобальное удаление по подстроке.

## Распространение

Поддерживать portable и installer. Для начала не нужны сайт, сервер, аккаунты, платная Pro или телеметрия. Удобное восстановление и надёжные правила очистки важнее количества функций.
