# Участие в разработке

Соберите приложение через `build.ps1`, затем запустите `AppShelf.exe --self-test --registry-fixture` в тестовой Windows. Изменения очистки должны включать тест, который работает только с уникальным временным разделом, и проверку восстановления.

Не тестируйте новые правила на рабочих настройках. Для расширения покрытия используйте виртуальную машину. В PR укажите сценарий, ожидаемое изменение поведения и результат проверок. Не прикладывайте пользовательские копии реестра, пути с личными данными, токены и полные журналы чужих приложений.

Код проекта распространяется по MIT. Улучшения алгоритма очистки должны сохранять предпросмотр, резервирование до записи и повторную проверку содержимого перед очисткой.
